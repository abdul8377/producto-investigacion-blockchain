# Configuración de Fabric

Variables de servidor: FABRIC_GATEWAY_ENDPOINT, FABRIC_PEER_HOST_ALIAS (opcional), FABRIC_CHANNEL, FABRIC_CHAINCODE, FABRIC_MSP_ID, FABRIC_TLS_CERT_PATH, FABRIC_IDENTITY_CERT_PATH y FABRIC_IDENTITY_KEY_PATH.

Las rutas apuntan a certificados locales fuera de Git. Para cifrar el detalle experimental B se requiere LAB_KEYS_DIR, una ruta absoluta fuera del proyecto con permisos restrictivos.

No colocar claves en variables NEXT_PUBLIC_.
